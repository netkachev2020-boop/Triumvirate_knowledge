Триумвират знаний (Educational AI Bot)

Многофункциональный бот для платформы МАКС и школьников (1–11 классы), работающий на базе локальной мультимодальной нейросети (через LM Studio). Проект сочетает строгие стандарты кода (PEP8), также код был проверен на утечку памяти в следствии чего утечки памяти не обнаруженно, модульную архитектуру и контейнеризацию (Docker).
Бот выступает в роли наставника для учеников и родителей и может выполнять 3 сценария.
Роли наставников
1. Сократ (Мудрый наставник): Никогда не дает готовый ответ сразу. Ведет ученика по шагам через наводящие вопросы. Помогает выйти из тупика при фразах вроде «не знаю».
2. Аналитик (Мастер структуры): Принимает тексты параграфов или фотографии страниц учебника и превращает их в готовые конспекты (Главная мысль, Ключевые термины, Тезисы, Вывод).
3. Проверяющий (Экзаменатор): Генерирует мини-тесты из 6 вопросов по указанной теме, а затем проверяет ответы ученика с разбором ошибок.

Технологический стек
1 Язык: Python 3.11+
2 Интерфейс: Платформа МАКС API (Long Polling, Markdown)
3 ИИ: OpenAI-совместимый API (локальная модель Qwen2.5-VL-7b через LM Studio)
4 Контейнеризация: Docker
5 Библиотеки: `requests`, `openai`, `Pillow`, `python-dotenv`, `urllib3`

Быстрый запуск (Локально)
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/твой-аккаунт/triumvirate-bot.git
   cd triumvirate-bot
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
3. Создайте файл .env в корне проекта и укажите токен бота:
   MAX_BOT_TOKEN=твой_токен_сюда
4. Запустите LM Studio локально на порту 1234 (с поддержкой Vision-модели).
5. Запустите бота:
   python main.py

Запуск через Docker
1. Соберите Docker-образ:
   docker build -t triumvirate-bot .
2. Запустите контейнер:
   docker run --env-file .env triumvirate-bot
